Blobs and files

A Blob is the browser's container for raw bytes: a chunk of data plus a type, like image/png. It's how a page handles anything that isn't text or JSON, such as images, audio, PDFs and zip files. A File is a Blob with a name. Nothing you pick or drop here leaves your computer: it all happens inside this page. Notes.

2. Blob URLs

URL.createObjectURL(file) gives the Blob a URL, so anything that takes a URL can use it: an <img src>, a link, a video. The bytes never leave the browser. The URL only points into this page's memory.
