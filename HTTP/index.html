HTTP

HTTP is the protocol under every page, image, script and fetch: the browser sends a request (method, URL, headers, maybe a body) and the server sends back a response (status, headers, maybe a body). That meaning hasn't changed since the 1990s. How it's carried has: first as lines of text, now as binary frames. Notes.
