Deno

Deno runs JavaScript outside the browser. A Deno server is one function: a Request goes in, a Response comes out, the same classes a page uses with fetch. So the server below, server.js, runs in two places at once: in this page, called directly with no network, and in Deno on your computer, called over HTTP. Same file, same answers; only ranIn differs. Notes.

For the right-hand column, start the server from the repo folder: deno serve --port 8001 Deno/server.js. The left-hand column needs nothing.
