The DOM API, 80/20

The DOM has hundreds of functions and properties, but about twenty of them do most everyday work: find an element, create one, attach, move or remove it, change its text, attributes, classes and style, and react to clicks. Pick a step, read the code, press Run, and see what it did to the page and to the tree. Edit the code and run your own too. Notes. New to the DOM? Start with DOM.
