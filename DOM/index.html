The DOM

The browser reads a page's HTML text once and turns it into a tree of objects in memory, the Document Object Model. It draws the page from those objects, and JavaScript changes the page by changing them. The HTML text itself is then set aside. Notes.

1. HTML in, DOM out

Type or edit HTML on the left. The browser's parser turns it into the tree on the right, the same way it does for a whole page. The tree has no closing tags, because objects don't need them: indentation shows what's inside what.
